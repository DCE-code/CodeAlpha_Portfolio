# CodeAlpha Personal Portfolio

A responsive personal portfolio website built for the CodeAlpha Frontend Development Internship — Task 3.

## Features

- Responsive layout for desktop, tablet and mobile
- Sections for introduction, about, skills, projects and contact
- Mobile navigation menu
- Smooth in-page navigation
- Subtle motion effects with reduced-motion support
- Project links to existing public work
- Email contact link

## Technologies

- HTML5
- CSS3
- JavaScript

## Run locally

1. Download and extract the project.
2. Open the folder in VS Code.
3. Open `index.html` in your browser, or use the VS Code Live Server extension.

No build step or package installation is required.

## Before submitting

- Review every project link and make sure it is still correct.
- Update the location text if needed.
- Add a resume link only if you have a current resume you want to publish.
- Test the layout on both mobile and desktop.
- Replace any project entry that you do not want to present.

## GitHub

Create a repository named `CodeAlpha_PersonalPortfolio`, then upload the contents of this folder.

## Deployment

You can deploy this static site using GitHub Pages, Netlify or Vercel. After deployment, add the live URL to your CodeAlpha submission.

This portfolio describes personal learning and concept projects accurately. It does not claim client commissions or professional employment that has not been stated.
